About JSONForgeKit

JSONForgeKit is a small set of free browser tools for JSON, YAML, and CSV. It is built and operated by Syed Fahad Ali. There is no account to create.

Why this site exists

JSONForgeKit exists so you can format, inspect, and convert data you already have, without signing in. The pages are small on purpose: each one does one job, then tells you what the browser actually did, including the cases where the output is not a character-for-character copy of the input.

Many JSON utilities only show a success message. These tools also document limits that come from the browser itself, such as how JavaScript stores numbers, how YAML 1.1 and YAML 1.2 disagree on words like yes, and how nested JSON becomes CSV columns. That is the reason the site was written this way.

JSONForgeKit is the name of this website. It is not a company, a team, or an office. Support is the Contact page, not a helpdesk.

Who it is for

The tools are for people who already have some JSON, YAML, or CSV and need to read it or change its shape. Developers often paste an API response to indent it, check a nested value, or flatten records for a spreadsheet. The same pages are usable for config files, exports, and sample payloads.

You do not need an account. Open a page and paste text. Most tools can also open a local file. Use the result in this browser.

How these tools behave

Formatting, viewing, conversion, copy, download, and opening a local file run in this browser. Text you paste or read from a file is not uploaded to a server run by this website. That does not describe every request the site can make: optional analytics and the contact form are separate, and the Privacy policy covers them.

The JSON Beautifier uses the browser’s JSON.parse and JSON.stringify. Beautify writes two-space indentation. Minify writes the same parsed value without extra whitespace. Because the value is parsed first, the result can differ from the input even when the JSON is valid: a repeated key keeps the last value, some integer-like keys are written in numeric order, a trailing .0 is not kept, integers outside JavaScript’s safe integer range can change, and -0 is written as 0. Validate JSON only updates the status line. It does not rewrite the text, and this site does not repair invalid JSON.

YAML is not one dialect. JSON to YAML writes YAML with quoting that is meant to keep strings such as yes and 01 as text for readers that still follow YAML 1.1. That quoting is practical help, not a claim of complete YAML 1.1 compatibility. YAML to JSON reads one YAML 1.2 document with the core schema, so unquoted yes and no stay strings, while true and false become booleans. A file with more than one document, separated by ---, is rejected. The two converters are not mirrors of each other.

JSON to CSV flattens nested objects into dotted column names such as address.city. Arrays stay in one cell unless you choose that array under Rows from, which uses those objects as rows and leaves the rest of the wrapper out. The table previews at most 100 rows; Copy CSV and Download CSV use the full conversion. If a dotted property and a nested object flatten to the same column, conversion stops instead of merging values.

The six tools

JSON Beautifier is the homepage. Paste JSON, then beautify it, minify it, validate the syntax, or copy the result. The input stays as you pasted it.

JSON Viewer turns JSON into an expandable tree. You can search keys and values, copy a path such as $.tags[0], or open a local .json file. A file larger than 5 MiB is rejected before it is read. Copy formatted JSON makes an indented copy without changing the editor.

JSON to CSV builds rows and columns from objects, with delimiter, header, and Rows from options. You can preview the table, copy the CSV, or download converted-data.csv.

JSON to YAML writes YAML from parsed JSON. Copy or download converted-data.yaml. YAML to JSON does the reverse for one YAML or YML document and downloads converted-data.json.

JSON Escape / Unescape works on a JSON string, not on formatting a whole object. Escape turns raw text into a quoted JSON string. Unescape expects those surrounding quotes and returns the text inside. This is not URL encoding or HTML encoding.

Privacy

The JSON or YAML you put in a tool is not the same as the optional analytics on this site. Google Analytics 4 loads only if you choose Accept analytics. Until then, and after you reject, this site does not request the Google tag.

Accept analytics grants analytics storage only. Advertising storage stays denied. The Privacy policy explains the consent banner, the saved choice in this browser, and how to open Privacy choices again.

The tools keep working if you accept analytics, reject it, or have not chosen yet.
