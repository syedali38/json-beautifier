About JSONForgeKit

JSONForgeKit is a small website of free JSON tools. Each page runs in your browser so you can format, inspect, or convert data without creating an account.

What this site is

JSONForgeKit is the name of this website. It is a collection of focused tools for JSON, YAML, and CSV, not a described company office or a support desk.

The homepage is a JSON Beautifier that formats, validates, and minifies JSON. The other pages cover jobs that sit next to that: reading a tree, turning objects into a spreadsheet, moving between JSON and YAML, and escaping a JSON string.

Who it is for

The tools are for people who already have some JSON, YAML, or CSV in front of them and need to read it or change its shape.

Developers often paste an API response to indent it, check a nested value, or flatten records for a spreadsheet. Students use the same pages to see how objects, arrays, and YAML mappings relate. Anyone working with config files, exports, or sample payloads can convert or inspect that text here.

You do not need an account. Open a page and paste text. Most tools can also open a local file. Use the result in this browser.

The six tools

JSON Beautifier is the homepage. Paste JSON, then beautify it with two-space indentation, minify it, validate the syntax, or copy the result. The input stays as you pasted it. Invalid JSON is reported; it is not rewritten for you. Trailing commas, single quotes, and comments are common reasons validation fails.

JSON Viewer turns JSON into an expandable tree. You can search keys and values, copy a path such as $.tags[0], open a local .json file, or load a small sample. Copy formatted JSON makes an indented copy without changing the editor. A file larger than 5 MiB is rejected before it is read.

JSON to CSV flattens objects into rows and columns. Nested objects become dotted names such as address.city. You can choose a comma, semicolon, or tab delimiter, include a header row, preview the table, copy the CSV, or download it. When JSON wraps an array of objects, Rows from can use that array as the records.

JSON to YAML writes the same values as YAML. You can paste JSON or open a .json file, then copy or download converted-data.yaml. Strings that a YAML 1.1 reader might treat as booleans or numbers, such as yes or 01, are quoted so they stay text.

YAML to JSON reads one YAML 1.2 document using the core schema. Open a .yaml or .yml file, or paste YAML, then copy or download JSON. Unquoted yes and no stay strings in this version of YAML. A file with more than one document, separated by ---, is rejected.

JSON Escape / Unescape works on a JSON string, not on formatting a whole object. Escape turns raw text into a quoted JSON string. Unescape expects those surrounding quotes and returns the text inside. This is not URL encoding or HTML encoding.

Processing in your browser

Formatting, viewing, conversion, copy, download, and opening a local file run in this browser. The text you paste or read from a file is not uploaded to a server run by this website.

JavaScript numbers cannot keep every integer exactly. Several tools mention that a very large whole number can change after it is parsed. The converters also describe their own limits, such as file size and which YAML features they reject.

Privacy

The JSON or YAML you put in a tool is not the same as the optional analytics on this site. Google Analytics 4 loads only if you choose Accept analytics. Until then, and after you reject, this site does not request the Google tag.

Accept analytics grants analytics storage only. Advertising storage stays denied. The Privacy policy explains the consent banner, the saved choice in this browser, and how to open Privacy choices again.

The tools keep working if you accept analytics, reject it, or have not chosen yet.
