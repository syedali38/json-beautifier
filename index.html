What Is a JSON Beautifier?

This JSON Beautifier uses two panels. Paste into JSON input. Beautify JSON and Minify JSON parse that text with the browser's JSON.parse, then write a new serialization to the read-only JSON result panel with JSON.stringify. The input stays as you pasted it.

Beautify JSON writes two-space indentation. Minify JSON writes the same parsed value without extra whitespace. Validate JSON also calls JSON.parse, but it only updates the status line under the editor. It does not fill or change the result panel.

Invalid JSON is not repaired. Beautify JSON and Minify JSON then clear the result panel. For an expandable tree instead of formatted text, use the JSON Viewer.

How to Use a JSON Beautifier Online

Step 1: Paste Your JSON

Paste one JSON value into JSON input. An object, array, string, number, boolean, or null is accepted. Leading and trailing spaces are ignored. A box that contains only spaces is treated as empty. This page does not open files.

Step 2: Beautify JSON

Choose Beautify JSON to write two-space indentation to JSON result, or Minify JSON for a compact line. The input is not rewritten. If parsing fails, the result panel is cleared.

Step 3: Validate JSON

Choose Validate JSON to check the input only. A successful check updates the status line. It does not fill the result panel, so Copy JSON still needs Beautify JSON or Minify JSON first.

Step 4: Copy Your JSON

Copy JSON copies the result panel, not the input. Clear empties both panels. If you edit the input after a successful Beautify or Minify, the previous result is cleared.

JSON Beautify vs Minify

Beautify JSON and Minify JSON both parse the input and write a new JSON text. They are not a whitespace-only pass. Duplicate keys, some object key order, and some numbers can change. Validate JSON does not rewrite anything.

Beautify

Parses the input, then writes JSON.stringify with two-space indent to the result panel. Use it when you want to read the structure.

Minify

Parses the input, then writes JSON.stringify without extra spaces to the result panel. Use it when you want a compact copy of the parsed value.

Validate

Parses the input and only updates the status line. The input and result panels stay as they are. A valid large integer can still change later if you Beautify or Minify it.

What Beautify and Minify Change Besides Whitespace

Because this page uses JSON.parse and then JSON.stringify, the result can differ from the input even when the JSON is valid. Validate JSON does not apply these changes.

Duplicate keys

If a key is repeated, JSON.parse keeps the last value. Beautify JSON and Minify JSON then write only that value.

Integer-like object keys

Keys that look like array indexes are written in numeric order, then the remaining keys. The names are not renamed.

JavaScript numbers

JSON.parse uses JavaScript numbers. A trailing .0 is not kept. Integers outside ±9007199254740991 can change. JSON.stringify writes -0 as 0.

Unicode

Non-ASCII characters stay as characters. Beautify JSON does not turn 東京 into \u escapes.

Common JSON Formatting Errors

Validate JSON, Beautify JSON, and Minify JSON all use JSON.parse. Failures are reported on the status line as Invalid JSON: plus the browser's parser message. That message wording varies by browser. This page does not rewrite the invalid text. Beautify JSON and Minify JSON also clear the result panel.

  1. Trailing commas

    A comma after the last value is invalid. Example: {"a":1,}

  2. Single quotes instead of double quotes

    JSON keys and strings must use double quotes. Example: {'a':1}

  3. Comments inside JSON

    // and /* */ are not allowed. Example: {"a":1} // note

  4. Unquoted property names

    Keys must be quoted strings. Example: {a:1}

  5. Extra JSON values

    Only one JSON value is parsed. Example: {"a":1}{"b":2}

  6. NaN and Infinity

    Those tokens are not JSON numbers. Examples: NaN and Infinity

Clear empties JSON input and JSON result, sets the status to Editor cleared, and focuses the input.

After a result is shown, any change in JSON input clears the result and the status. Copy JSON then has nothing to copy until you Beautify or Minify again.

Frequently Asked Questions

Does the JSON Beautifier fix invalid JSON?

No. Invalid JSON is reported on the status line. Beautify JSON and Minify JSON clear the result panel. Trailing commas, single-quoted strings, comments, and the other errors above are not rewritten.

Why did a number or key order change after Beautify?

Beautify JSON and Minify JSON re-serialize the parsed value. 1.0 becomes 1, 9007199254740993 becomes 9007199254740992, -0 becomes 0, a repeated key keeps the last value, and integer-like keys such as 1, 2, and 10 are written in numeric order.

Does my JSON leave the browser?

Beautify, minify, validate, copy, and clear run in this browser. The JSON in the editors is not uploaded to a server. Optional Google Analytics loads only if you choose Accept analytics. That choice is not the JSON you paste.

Why does Copy JSON require Beautify or Minify first?

Copy JSON reads the result panel. Validate JSON does not write that panel. If the result is empty, the status is Beautify or minify JSON first.

Does Validate change my JSON?

No. Validate JSON only updates the status line. The input and result panels stay as they are.
