What Is JSON to CSV Conversion?

JSON to CSV conversion turns structured JSON into rows and columns that a spreadsheet can open. A json to csv converter reads each object as one record and each property as a column. You can convert json to csv online on this page without sending the text to a server.

How to Convert JSON to CSV

Step 1: Add JSON

Paste an object or an array of objects, upload a .json file, or choose Load sample JSON.

Step 2: Choose options

Pick a comma, semicolon, or tab delimiter, and choose whether the first row names the columns.

Step 3: Convert and preview

After you paste JSON, choose Convert to CSV. A valid uploaded file and Load sample JSON convert immediately. The preview shows the columns and up to 100 rows.

Step 4: Copy or download

Copy the CSV or download converted-data.csv. Download CSV contains all converted rows, not only the preview.

JSON to CSV Examples

Plain object

{"name":"Ali","age":30}

A single root object becomes one CSV row:

name,age
Ali,30

Array of objects

JSON array to CSV conversion turns a top-level non-empty array of objects into one CSV row per object.

[
  {
    "name": "Ali",
    "age": 30,
    "address": { "city": "Karachi", "country": "Pakistan" }
  }
]

The converter flattens address into dotted columns:

name,age,address.city,address.country
Ali,30,Karachi,Pakistan

Array property

[{"name":"Ali","tags":["design","json"]}]

The CSV preview displays ["design","json"] in the tags cell. The downloaded CSV quotes this field because the JSON text contains commas and quotation marks. The array remains in one CSV cell. It does not create additional CSV rows. 

name,tags
Ali,"[""design"",""json""]"

One object containing an array

{
  "records": [
    {"name": "Ali"},
    {"name": "Sara"}
  ]
}

With Rows from set to Whole JSON, this is one object. The records array stays in one CSV cell: 

records
"[{""name"":""Ali""},{""name"":""Sara""}]"

Choose records under Rows from to use the objects inside that array as rows. Pasting the inner array with Whole JSON selected also creates those rows: 

[{"name":"Ali"},{"name":"Sara"}]
name
Ali
Sara

Missing property and null

[{"name":"Ali"},{"name":"Sara","note":null}]

Ali has no note property, so that cell is blank. Sara has a JSON null, so the cell is the text null.

name,note
Ali,
Sara,null

Nested JSON Conversion Explained

Nested object properties are flattened into dotted column names, so user.name and user.city stay separate. An empty nested object is kept as {} in one cell. If a property is missing from one record, that cell is left blank. A JSON null stays visible as the text null, so it is not confused with a missing property.

JSON numbers, true, and false are written as cell text. CSV text does not keep the original JSON types. A very large whole number can change when JavaScript parses the JSON, because not every integer can be represented exactly.

An array inside an object stays in one cell when Rows from is Whole JSON. That keeps every item instead of dropping the list or inventing extra rows. Choose that array under Rows from when every item is an object and you want one row per object. Arrays reached only by going through another array are not offered. A top-level array is converted only when every item is an object.

Common Conversion Errors

Invalid JSON

Trailing commas, comments, and single quotes are rejected. The status line shows the parser message.

Unsupported root

A top-level string, number, boolean, or null is rejected. An array is accepted only when every element is an object, so an array of strings is rejected. An empty object has no properties, so it produces no CSV columns. The status message identifies the error. The converter does not rewrite invalid or unsupported input.

Empty array

An empty array has no records, so no CSV file is created until you add objects.

Conflicting column names

If a dotted property and a nested object flatten to the same column, conversion stops. The status line names that column, and the preview is cleared. Values are not merged.

Input too large

Pasted JSON longer than 12,000,000 characters is not converted. A file larger than 12,000,000 bytes is not read. The editor is left as it was.

Frequently Asked Questions

Does this json to csv tool upload my data?

No. Parsing, flattening, preview, copy, and download all run in your browser.

How are commas and quotes handled?

Fields that contain the delimiter, a double quote, or a line break are wrapped in double quotes. Quotes inside a field are doubled.

What does spreadsheet-safe export change?

Nothing, unless you check Spreadsheet-safe export. It is off by default, so the CSV keeps the original cell text.

Can I convert a JSON file to CSV?

Yes. Upload a local .json file to convert a JSON file to CSV. Supported JSON is converted in your browser. A file larger than 12,000,000 bytes is rejected and is not read.

Where can I inspect the JSON first?

Use the JSON Viewer to open the tree, or the JSON Beautifier to format the text, then come back and convert it. Use the JSON to YAML converter when you need a structured configuration document instead of a spreadsheet table. Use JSON Escape and Unescape when you need to encode or decode a JSON string.
