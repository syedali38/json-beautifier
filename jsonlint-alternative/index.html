Is JSONForgeKit free?

Yes. All six tools are free, with no signup and no paid tier.

View JSON as a collapsible tree with search and copy path, convert JSON to CSV or YAML (and YAML back to JSON), and escape or unescape JSON strings. JSONLint's main page offers validation, formatting and compression.

Yes. The JSON to CSV converter flattens nested objects to columns; the JSON to YAML converter gives clean YAML instantly. Both are free and run in your browser.

Is JSONForgeKit safe for API responses with tokens?

Yes. Because nothing is uploaded, tokens, credentials and internal IDs in your JSON stay on your device.
