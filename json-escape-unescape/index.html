What JSON String Escaping Does

JSON string escaping makes quotes, backslashes, and line breaks safe inside a JSON string. Use this JSON escape online tool to convert plain text into a valid JSON string, or unescape an encoded JSON string back into readable text. This tool handles string escaping, not JSON object formatting. To format or beautify a JSON object, use the JSON Beautifier. The result is a JSON string escape, not URL encoding and not HTML encoding.

Escape reads the input as raw text. If you paste an already escaped string and choose Escape again, the quotes and backslashes are escaped a second time. Use Unescape to reverse one level.

How to Escape and Unescape JSON

Step 1: Add text

Paste raw text to escape, or one quoted JSON string to unescape.

Open Text/JSON File accepts .txt and .json files up to 5 MiB and fills the input box. Opening a file does not Escape or Unescape. A rejected file leaves the current text unchanged.

Step 2: Choose an action

Choose Escape or Unescape. The status line reports success or the problem.

Step 3: Read the output

Escaped output includes the surrounding double quotes. Unescape removes them.

Step 4: Copy, download, or clear

Copy output and Download output use the last successful conversion. Neither button converts the current input. Editing the input leaves the previous output visible, but that result is no longer valid. Choose Escape or Unescape again before Copy or Download will work.

After Escape, Download output saves json-escaped.txt. After Unescape, it saves json-unescaped.txt. Clear empties both boxes.

A JSON document

Escape treats this document as raw text. It does not parse or reformat it. The result is a JSON string literal, and the surrounding double quotes are part of the output. Unescape accepts that escaped string and returns the original text. A bare JSON object is not accepted by Unescape.

Raw input

Escaped output

Line breaks and Unicode

A newline becomes \n, a tab becomes \t, and a carriage return becomes \r. Backspace becomes \b and form feed becomes \f. Other control characters may be written with \u00XX notation. Characters such as 東京 and emoji stay as themselves. The line separators U+2028 and U+2029 are written as \u2028 and \u2029.

Raw input, with a newline between the lines

Line 1
Line 2

Escaped output

"Line 1\nLine 2"

Raw input, with a tab between the letters

a	b

Escaped output

"a\tb"

Raw input, with a carriage return between the letters

ab

Escaped output

"a\rb"

Browser text boxes may normalize carriage returns to line feeds. When this happens, a carriage return entered in the text box is escaped as \n rather than \r.

Invalid Escape Sequences

Unescape accepts one JSON string, including the surrounding double quotes. Whitespace around that string is allowed. Text after the closing quote is rejected.

\x41, \a, a short \u12, and an unpaired \uD800 are rejected. An object, array, number, boolean, or null is rejected. The output box is cleared when conversion stops.

Escape and Unescape both stop when the input is longer than 2,000,000 characters. The text is not shortened.

A file larger than 5 MiB is rejected before it loads. Pasted text is not subject to that file-upload size limit. Conversion still uses the 2,000,000-character limit above.

Frequently Asked Questions

Does this tool upload my text?

No. Escape, unescape, copy, opening a local file, and downloading the generated text all run in your browser.

Is this a string unescape tool?

Yes, for one quoted JSON string. It decodes escaped quotes, backslashes, newlines, tabs, and Unicode escapes such as \u6771. This string unescape does not decode URL percent-encoding such as %20, or HTML entities such as &quot;.

Do the results include quotation marks?

Escape adds the surrounding double quotes. Unescape requires those quotes and returns the text inside them.

How do I unescape JSON online?

Paste one JSON string, including the surrounding double quotes, and choose Unescape. The output is the text inside the string. Parsing and copy run in your browser.

Why does JSON unescape fail?

Unescape accepts one quoted JSON string. A bare object, array, number, true, false, or null is rejected, and the output is cleared. A missing quote, an invalid escape such as \x41, or text after the closing quote also stops the conversion. Unpaired Unicode surrogates are rejected on Escape and Unescape.

Why is the old output still visible after I edited the input?

Editing the input does not clear the output box. That previous result is no longer valid for Copy output or Download output. Choose Escape or Unescape again.

What file does Download output save?

After Escape, Download output saves json-escaped.txt. After Unescape, it saves json-unescaped.txt. The file contains the last successful conversion.

Where can I format the JSON first?

Use the JSON Beautifier to format a document, the JSON Viewer to inspect a tree, or the JSON to CSV and JSON to YAML tools when you need another format. If your source data is YAML, use the YAML to JSON converter to convert it into JSON first.
