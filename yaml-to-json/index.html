What Is YAML to JSON Conversion?

          

            YAML to JSON conversion writes the same values as a JSON document.
            A YAML to JSON converter turns each mapping into an object and each sequence into an array.
            You can convert YAML to JSON online here without sending the text to a server.
          

          

            This page reads YAML 1.2 using the core schema. It converts one document.
            A .yml file is YAML too, so the same converter can turn YML to JSON.
            The download is converted-data.json.
          

        


        

          
How to Convert YAML to JSON

          

            

              
Step 1: Add YAML

              
Paste YAML into the editor, or open a .yaml or .yml file from this browser. A valid file is converted as soon as it is read. Load Sample YAML converts immediately.

            

            

              
Step 2: Convert

              
For pasted YAML, choose Convert to JSON. Invalid YAML stays in the editor, and the status line explains the problem.

            

            

              
Step 3: Read the JSON

              
The preview shows JSON with two-space indentation. Changing the YAML clears that preview until you convert again.

            

            

              
Step 4: Copy or download

              
Copy JSON copies the preview. Download JSON saves converted-data.json.

            

          

        


        

          
YAML to JSON Examples

          
Nested values

          
name: Ada
active: true
score: null
tags:
  - yaml
  - json
address: {}
notes: []


          
{
  "name": "Ada",
  "active": true,
  "score": null,
  "tags": [
    "yaml",
    "json"
  ],
  "address": {},
  "notes": []
}

          
Words and quoted text

          

            Unquoted yes and no stay strings. A quoted number-like value stays text, so "01" does not become the number 1.
          

          
flag: yes
other: no
code: "01"


          
{
  "flag": "yes",
  "other": "no",
  "code": "01"
}

          
A line break inside a string

          
message: |
  line1
  line2


          
{
  "message": "line1\nline2\n"
}

        


        

          
YAML Numbers in the Browser

          

            JSON.parse is not used here, but the result is still a JavaScript value.
            A whole number and the same number written as 1.0 become one JSON number.
            Integers outside ±9007199254740991 can change. The JSON shows the number JavaScript kept.
          

          
Input

          
small: 1.0
big: 9007199254740993


          
Output

          
{
  "small": 1,
  "big": 9007199254740992
}

        


        

          
Common Conversion Errors

          
Invalid YAML

          
A broken sequence, a bad indent, or other syntax the parser rejects stays in the editor. The status line includes the parser message. The preview is cleared.

          
Empty input

          
An empty editor, a comment with no document, an empty file, or a file that contains only whitespace has nothing to convert. YAML null and ~ are values, and those become JSON null.

          
More than one document

          
A file with two documents separated by --- is rejected. This page converts one YAML document.

          
Duplicate keys and unsupported YAML

          

            A mapping key cannot be repeated. Custom tags, binary data, merge keys, and a circular alias are rejected instead of being rewritten into a different JSON value.
            An alias that simply repeats a value is written out in full.
          

          
Input too large

          
A YAML file larger than 5 MiB is rejected before it is read. Pasted YAML longer than 5,000,000 characters is not converted. The editor is left as it was.

        


        

          
Frequently Asked Questions

          
Does this YAML to JSON tool upload my data?

          
No. Parsing, conversion, copy, and download all run in your browser.

          
Can I open a .yml file?

          
Yes. Open YAML File accepts .yaml and .yml. Both are read as YAML text. The downloaded file is converted-data.json.

          
Why did yes stay a string?

          
This converter uses YAML 1.2. In that version, an unquoted yes or no is text. It is not the boolean true or false.

          
Where can I work with JSON the other way?

          

            Use the JSON to YAML converter to write YAML,
            the JSON Beautifier to format JSON, or the
            JSON Viewer to inspect the tree.
